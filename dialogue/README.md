# Как делать диалоги персонажей

Формат строки в `.dialogue`:

```
Имя персонажа: текст реплики
```

Имя до двоеточия автоматически попадает в `dialogue_line.character` и
используется баллоном для выбора мини-портрета.

## Портреты
1. Нарисуй квадратный PNG и положи в `res://assets/portraits/`.
2. В `dima_small_balloon.gd` добавляешь/правишь словарь:

```gdscript
@export var portraits: Dictionary = {
	"Дима": "res://assets/portraits/dima.png",
	"Охранник": "res://assets/portraits/guard.png",
}
```

3. Если у персонажа нет картинки — показывается `placeholder.png`.

## Памятка
- `~ start` — точка входа, `=> END` — конец.
- Переход к следующей реплике — по пробелу.
- Все текущие диалоги — от Димы, их можно редактировать в `popup_*.dialogue`.

# Seva Pidor: Remastered — памятка

## Структура (классический Godot 4)
```
res://
  project.godot
  assets/
	sprites/        — все спрайты (палитра duel.hex)
	audio/          — музыка, звуки, dima_voice.mp3
	portraits/      — мини-портреты персонажей диалогов
  scenes/
	levels/         — LEVEL_2.tscn … LEVEL_20.tscn, game_over.tscn,
					  main_menu.tscn, titles.tscn, level_selector.tscn
	objects/        — Obj_<id>.tscn (инстансы префабов для игроков)
	prefabs/        — player / gun_player / topview_player / scroller_shooter_player
	ui/             — dima_small_balloon.tscn
  scripts/
	autoload/       — GameState.gd
	player/         — player_master.gd
	enemies/        — enemy.gd
	entities/       — anim_sprite, bullet, solid_block, interactive, ...
	ui/             — hud_widgets.gd
	dialogue/       — dima_small_balloon.gd
	roles/          — по скрипту на роль объекта (см. ниже)
  dialogue/         — popup_*.dialogue, _TEMPLATE.dialogue, README.md
  addons/           — Dialogue Manager (не трогаем)
```

Шрифт везде: `assets/fonts/modula.ttf`, глобальная тема
`assets/fonts/modula_theme.tres` подключена через `[gui] theme/custom`.
Диалоговый баллон дополнительно явно использует Modula (Theme в сцене).

## Диалоги и портреты
- `GameState.show_popup()` ставит `dialogue_active = true`, включает
  `PROCESS_MODE_ALWAYS` для BGM и баллона, затем ставит игру на паузу. Игрок не
  двигается и не получает урон, пока идёт диалог. Пауза снимается по
  `dialogue_ended`, затем `Input.flush_buffered_events()`. Музыка играет всё время.
- Портрет берётся по имени из строки `Имя: текст` из словаря `portraits` в
  `scripts/dialogue/dima_small_balloon.gd`; картинки — в `assets/portraits/`.
  Нет картинки → `placeholder.png`.
- Шаблон: `dialogue/_TEMPLATE.dialogue`, инструкция: `dialogue/README.md`.
  Все текущие реплики — от Димы. Окно диалога 320 px, внизу по центру,
  переход по пробелу.

## Анимации урона и смерти
- Игрок: `tex_hit` / `frames_hit`, `tex_dead` / `frames_dead` из оригинальных
  `hit_sprite` / `dead_sprite`. Hurt держится `hurt_invuln_time = 0.6` с,
  обычные анимации его не перебивают. Dead замораживает последний кадр,
  затем `death_delay = 2.0` с и только потом экран проигрыша.
- Враги: `tex_hit` / `frames_hit` на 0.15 с при уроне.
- Смерть от падения за нижнюю границу тоже идёт через `_die()` (анимация
  проигрывается перед экраном проигрыша).
- `GameState.kill_player()` запоминает сцену в `last_death_scene`; кнопка
  «Попробовать ещё раз» на GAME OVER вызывает `GameState.retry_level()` и
  перезапускает именно тот уровень, где игрок умер.
- Конвертер в `C:\Users\devil\PycharmProjects\GameCreator-to-Godot` обновлён —
  новые сборки вытаскивают эти спрайты автоматически.

## Сохранения
- Автосохранение (`AutoSave.gd` в autoload) слушает `scene_changed`, поэтому
  срабатывает при **каждой** смене сцены, а не только при старте игры.
  Уровни: **3, 6, 8, 11, 12, 17, 18, 19**. В правом верхнем углу появляется
  «СОХРАНЕНИЕ...» на 1.3 с, затем пишется `user://seva_save.cfg`
  (сцена, hp, score, keys).
- В `main_menu.tscn` есть кнопка **«Продолжить»** — `GameState.load_game()`
  загружает последнее сохранение и переносит hp/score/keys.
- Кнопка «Попробовать ещё раз» на `game_over.tscn` перед перезапуском
  восстанавливает `hp = max_hp` (для всех видов игрока).
- `GameState.lose_scene` указывает на `res://scenes/levels/game_over.tscn`.

## Скрипты по ролям
Монолитный `interactive.gd` разбит: `scripts/roles/role_base.gd` держит общие
свойства и switch-логику, а конкретные роли — отдельные файлы:
`switch.gd`, `collectable.gd`, `powerup.gd`, `key.gd`, `finish_level.gd`,
`hurting_zone.gd`, `teleport_start.gd`, `teleport_end.gd`, `door.gd`,
`ladder.gd`, `track_selector.gd`, `design.gd`. В сцене `Obj_*.tscn` у каждого
объекта теперь свой скрипт по полю `role`.

## Движущиеся блоки и скейт
`scripts/roles/moving_block.gd` (AnimatableBody2D, `sync_to_physics = true`):
возит игрока, включается свитчем в том числе по соседству (`on_nearby_switch`),
разворачивается у стены через RayCast2D. 4 таких блока пропатчены.

## Слои коллизий
- биты: **1** — мир/блоки, **2** — актёры, **4** — ящики (3-й слой = бит 4!);
- враги: `layer = 2`, `mask = 1` — только блоки;
- игрок: `layer = 2`, `mask = 5` (биты 1+4) — блоки и ящики, не актёры;
- ящики: `layer = 4`, `mask = 3` (биты 1+2) — блоки и игрок;
- пули и Area2D-триггеры: `mask = 7`.

Раньше было `mask = 1|3 = 3`, что включало слой актёров — враг физически
толкал игрока в статичный блок. Теперь они проходят друг сквозь друга, а урон
идёт через расстояние / Area2D / пули.

## Рукопашный рывок врагов
У врагов без пуль, но с уроном, включён `melee_enabled = true`.
В `_ready` создаётся Area2D радиуса `melee_range`; когда игрок входит в зону
(или оказывается рядом), враг несколько кадров (**`melee_dash_time`**, 0.18 с)
летит вперёд с **`melee_dash_speed`** 650 px/s и бьёт, только когда реально
догнал игрока (расстояние < 42 px). Так удар не кажется «дистанционным».
Все параметры — `@export`: `melee_enabled`, `melee_range`, `melee_lunge_speed`,
`melee_dash_speed`, `melee_dash_time`, `melee_cooldown`, `melee_damage`.
У стреляющих врагов `melee_enabled = false`.

## Имена объектов
Корневые узлы в `scenes/objects/Obj_<id>.tscn` переименованы по/script-роли:
`Switch_...`, `Collectable_...`, `Enemy_...`, `Block_...`, `MovingBlock_...` и т.д.

## Отталкивание
При уроне игрок и враги теперь реально отскакивают: на 0.18 / 0.16 с управление
полностью забирает импульс (260 / 220 px/s), затем он затухает.

## Направление движения врагов
`enemy.gd`: `move_direction = 1` — строго влево, `2` — строго вправо,
`3` (или `random_direction = 1`) — случайное направление, `0` — стоит.
Столкновение со стеной разворачивает патрулирующего врага.
Причина «все идут влево»: `move_vec` по умолчанию был `Vector2.LEFT`, а условие
инициализации проверяло только нулевую длину. Теперь в `_ready()` он сразу
ставится по `move_direction`.

Игрок и враги при получении урона получают слабое короткое отталкивание
(knockback 90 / 70 px/s, затухает за ~0.2 с) — только для отдачи, без урона.
